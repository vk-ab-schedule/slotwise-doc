# SlotWise — документация

SlotWise — веб-сервис, который строит расписание экзаменов, консультаций, предзащит и защит без конфликтов и с равномерной нагрузкой на преподавателей. Командный проект ИТМО, защита — 22 января 2027.

Этот репозиторий — единственный источник правды по проекту ([D-01](DECISIONS.md#d-01)).

## Как предложить изменение

1. Создать ветку `docs/<номер issue>-<кратко>` от `main`.
2. Внести правки. Если меняется поведение продукта, модель или процесс — добавить запись в [DECISIONS.md](DECISIONS.md) со статусом «Предложено».
3. Открыть PR в `main`; команда обсуждает правки в нём.
4. После апрува смержить и сменить статус решения на «Принято».

Подробнее — в [DEVELOPMENT.md](DEVELOPMENT.md#документация).
